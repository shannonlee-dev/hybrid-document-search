# v0.1.0 — Hybrid Document Search

Sparse·Dense·Hybrid 검색을 비교하고 API와 UI로 제공하는 첫 서비스 코드 릴리스입니다.

2026-10-21에 최종 머지 커밋 [`cb917ea`](https://github.com/shannonlee-dev/hybrid-document-search/commit/cb917eae0768c97c2ca63bbdbde15f24e85a77ed)에서
[v0.1.0 Release](https://github.com/shannonlee-dev/hybrid-document-search/releases/tag/v0.1.0)로 공개했습니다.

## 주요 기능

- TF-IDF·BM25·BGE-M3 Dense·BM25 + Dense score fusion 검색
- FastAPI 검색 API, 방식별 준비 상태와 오류 응답
- Streamlit 검색·두 방식 비교·검색어 강조·세션 검색 기록
- 공통 데이터 준비, Dense FAISS 인덱스 생성·저장·복원
- MIRACL·StrategyQA에서 품질 지표와 검색 시간 비교, RRF baseline 제공
- 요구사항·아키텍처·운영·평가 문서와 실행 검증 기록

## 실행 방법

Python 3.12 이상과 uv를 준비하고, 이 태그의 소스를 받은 뒤 저장소 루트에서 실행합니다.

```bash
uv sync --locked --extra sparse --extra dense
uv run --no-sync python -m scripts.prepare_dataset --download
uv run --no-sync python -m scripts.build_index \
  --corpus data/processed/corpus.jsonl --index indexes/dense --device cpu
DENSE_INDEX_PATH=indexes/dense uv run --no-sync uvicorn app.api:app
```

별도 터미널에서 UI를 실행합니다.

```bash
uv run --no-sync streamlit run frontend/app.py
```

## 알려진 제한

- 데이터·모델·인덱스는 소스에 포함하지 않습니다. 최초 준비 시 다운로드와 저장 공간이 필요합니다.
- API의 `hybrid`는 score fusion이며, 평가 CLI의 `hybrid` 별칭은 RRF입니다.
- 인증·요청 제한·캐시는 제공하지 않습니다.
- 검색 품질·시간은 문서에 명시한 데이터와 측정 조건의 결과입니다.
- 장시간 안정성·동시 부하 한계·브라우저 수동 검증은 이번 릴리스의 통과 조건에 포함하지 않습니다.
