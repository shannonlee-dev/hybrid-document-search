# BC Card Adaptive Hybrid 실행 결과

2026-10-29 측정. Train으로 학습하고 validation에서 60개 후보 중 weight·router를 선택한 뒤, 설정을 동결하고 test를 한 번 평가했다.
가중치 20조합과 Router 3종을 동일한 데이터·선택 규칙으로 비교했다.

공식 test 1,000개는 이전 Adaptive 탐색에서도 이미 평가한 이력이 있다.
‘test 1회’는 이번 실행에서 설정을 동결한 이후의 평가 횟수이며, 새로운 미사용 Test에 대한 독립 검증을 의미하지 않는다.

## 선택 및 결과 해석

- 선택 모델: logistic; BM25 weight는 keyword-heavy 0.20, balanced 0.10, semantic-heavy 0.00.
- 후보: weight 20세트 × Logistic Regression / small MLP / shallow tree = 60개.
- Primary validation Fixed nDCG@10 0.799644, 선택한 Adaptive 0.802480.
- Primary test Adaptive−Fixed nDCG@10: -0.001047 (degraded).
- Test mode 분포: `{'balanced': 1000}`.
- Adaptive 평균 검색 시간은 Fixed의 약 2.43배.
- 서비스 기본값은 Fixed Score Fusion을 유지한다.
- Validation 전체 1,000개에서 선택한 Router는 balanced를 선택했다.
- MLP 후보 [0.40, 0.20, 0.10]은 L-BFGS의 사전 반복 한도 500회에 도달했다. 해당 후보를 그대로 비교했으며 반복 수를 재조정하지 않았다.

| BPR이 높으면 어떤 의미인가요? | balanced | 0.500000 |

**Test의 모든 질문에서 balanced를 선택했다.** 관찰된 품질 차이는 해당 가중치를 고정 적용한 결과와 같으며, 질문별 라우팅의 추가 기여를 입증하지 않는다.

관찰된 개선·동률·악화와 계산 비용을 그대로 기록했다. Test 결과를 보고 후보나 모델을 재튜닝하지 않았다.
통계적 유의성을 검정하지 않았다. 관찰된 차이를 유의한 개선이나 독립 표본에 대한 일반화 개선으로 단정하지 않는다.
개별 사례만으로 label 불균형이나 feature 부족을 원인으로 확정하지 않는다.

## 검증·재현

- 관련 테스트: adaptive / fusion / enterprise evaluation 123 passed; 해당 변경의 Ruff 검사 통과.
- 기존 FP32·batch 1 벡터 캐시 `artifacts/bccard-adaptive-vectors-resumed` 재사용.
- 학습 데이터: 공식 train 43,394개. 선택 지표: non_synthetic validation 745개의 평균 binary nDCG@10.
- Test 전에 모델·후보·선택 결과와 코드·데이터·인코딩 해시를 동결하고 동일성을 검사했다.
- 전체 slice와 Top-3 근거는 [summary.json](experiments/adaptive/summary.json)에 기록했다.
- 공유 요약은 모델 revision·벡터 해시를 포함하며, 전체 query ID 목록과 중복 메타데이터는 제외했다. 원본 `encoding.json`은 로컬 벡터 캐시에 보존한다.
